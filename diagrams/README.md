# Diagrams

| Folder | Content |
| --- | --- |
| `src/` | Editable sources: draw.io (`.drawio`), PlantUML (`.puml`), Mermaid (`.mmd`) |
| `exports/` | Exported images for documents and slides (`.png`, `.svg`, `.pdf`) |

Rules:
- Always commit the **source** together with the export.
- Use the same file name: `src/context.puml` → `exports/context.png`.
- Export again after every change of the source.

Suggested diagrams: context, containers (components), use cases, ER diagram,
sequence diagram of a voice answer, deployment.
