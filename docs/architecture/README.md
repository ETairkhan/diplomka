# Architecture Decision Records (ADR)

An ADR is a short note about one important technical decision:
the context, the decision, and its consequences.

Rules:
- One decision per file: `NNNN-short-title.md` (for example `0002-use-fastapi.md`).
- Copy `adr-template.md` to start a new ADR.
- Do not delete old ADRs. If a decision changes, write a new ADR and mark the old one as "Superseded".
